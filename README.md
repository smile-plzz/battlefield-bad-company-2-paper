# Battlefield: Bad Company 2 — Interdisciplinary Academic Research Project

## Project Overview
This repository hosts the interdisciplinary academic investigation, analytical matrices, peer-review artifacts, and complete research manuscript for the study:

**"War as Entertainment: Military Satire, Squad Identity, Destructive Gameplay, and the Spectacle of Violence in Battlefield: Bad Company 2"**

- **Primary Discipline:** Game Studies
- **Secondary Disciplines:** Media Studies, Military Studies, Political Communication, Narrative Studies, Psychology of Interactive Media, Cultural Studies, Digital Humanities
- **Citation Style:** APA 7th Edition
- **Target Manuscript Length:** 7,000–9,000 words (excluding references and appendices)
- **Primary Game Object:** *Battlefield: Bad Company 2* (DICE / Electronic Arts, 2010)
- **Pipeline Framework:** Academic Research Skills (ARS v3.24.1 / commit `2e02041a3b821a160d98c9398f173c484ac759a8`)
